## Kastet micro kernel

This is a test for a micro kernel to be used in ARM chipsets, because I got pissed
with espressif

## How to run

* _make_
* _make run_

## Requirements 
* Linux
* Qemu (for testing)
* Assembly 
* C 

## Installing required dependencies 

For assembly:
* sudo apt install nasm 

For Qemu

* sudo apt install qemu qemu-system-x86
